# UURemoteKit

A Swift package that connects to computers running UU Remote (网易UU远程) and gives your app their desktop, terminals and TCP ports.

UURemoteKit is an independent client of the UU Remote protocol. NetEase does not make, endorse or support it. It came out of [Rayon](https://github.com/mizorewww/Rayon), which uses it.

## What it does

- **Account**: QR, SMS or token sign-in. The credentials live in storage your app provides; the keychain storage is built in. You also get the account's devices and whether each one is online.
- **Desktop**: the host's screens as decoded `CVPixelBuffer` frames. H.265 is decoded with VideoToolbox. You also get the host's cursor, and you can send pointer, wheel, keyboard and text input. Clipboard sync works in both directions, and you can change picture settings or switch screens.
- **Terminals**: the host's shell sessions. They keep running on the host after you disconnect, and you can list them and attach to them again.
- **Port mapping**: TCP streams to services on the device, such as its `sshd`. Each stream is handed to you as one end of a socket pair.

The host allows one control session per viewer. `UURemoteConnections` enforces this: while a desktop is open, the device's terminals and streams share its connection.

## Requirements

- macOS 13 or iOS 16
- Swift 6

The kit depends on [swift-protobuf](https://github.com/apple/swift-protobuf) and the [WebRTC SDK](https://github.com/stasel/WebRTC).

## Installation

```swift
.package(url: "https://github.com/mizorewww/UURemoteKit.git", from: "0.1.0")
```

## Usage

```swift
import UURemoteKit

let account = UURemoteAccount(
    storage: UUKeychainCredentialStorage(service: "com.example.app.uu", account: "default"),
    clientName: "Example"
)
try await account.startQRLogin()          // show account.qrImageData; scan it in the UU Remote app
let connections = UURemoteConnections(account: account)

// A desktop
let target = UURemoteTarget(deviceID: account.desktopDevices[0].deviceID)
let desktop = connections.desktop(for: target)
desktop.onFrame = { frame in /* draw frame.pixelBuffer; called off the main actor */ }
desktop.onEvent = { event in /* phase, screens, cursor, clipboard, network… */ }
desktop.start()
desktop.movePointer(x: 0.5, y: 0.5)

// A terminal, on the desktop's connection while it is open
let connection = try await connections.acquire(target)
let session = connection.openTerminal(cols: 80, rows: 24) { frame in /* frame.payload is output */ }
connection.sendTerminalInput(Data("ls\n".utf8), sessionID: session)
connections.release(connection)

// A port-mapped stream to the device's sshd
let fd = try await connections.openStream(to: target, host: "127.0.0.1", port: 22)
```

## Layout

| Folder | Contents |
| --- | --- |
| `Account` | Request signing, the REST client, sign-in, devices, credential storage |
| `Signaling` | Rooms and their Socket.IO socket; `gzip_sdp` through the Compression framework |
| `Transport` | `UUPeerTransport`, its WebRTC implementation and the H.265 decoder |
| `Connection` | One control session (`UURemoteConnection`) and the per-device registry |
| `Protocol` | Control messages, generated by swift-protobuf from `Protos/`, plus input JSON |
| `Clipboard`, `Terminal`, `PortMapping` | The services that run on a connection |

To regenerate the protobuf code after editing `Protos/`, run `Scripts/generate-protos.sh`.

## Testing

```sh
swift test
```

The tests never reach UU's servers:

- The wire formats are checked against byte-exact expected values.
- The WebRTC transport runs against an in-process peer that plays the host over loopback.
- The H.265 decoder is fed HEVC encoded locally by VideoToolbox.
- The port-mapping tunnel runs against a host that echoes what it receives.
